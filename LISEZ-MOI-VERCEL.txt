MINI MAISONS - LE SITE WEB (VERCEL)
===================================

Le site complet de Mini Maisons, déjà compilé, c'est le dossier
vercel\site (le zip MiniMaisons-vercel.zip contient exactement la même
chose). Il n'y a rien à construire. Il s'ouvre dans Safari sur iPhone, et
sur ordinateur (Chrome, Edge, Safari, Firefox). Les comptes, messages,
maisons et points sont les mêmes que dans l'appli Android (même base
Firebase).

IMPORTANT : GitHub et Vercel n'ouvrent pas les zip. Si tu envoies le zip
tel quel, Vercel ne trouve pas index.html et affiche
« 404 : This page doesn't exist ». Il faut envoyer les FICHIERS du site.


1. METTRE LE SITE EN LIGNE
--------------------------

Méthode A - avec GitHub (sans rien installer)
  1. Sur github.com, crée un dépôt (par exemple « mini-maisons-site »).
  2. Ouvre le dossier vercel\site dans l'Explorateur Windows (ou
     décompresse le zip : clic droit > « Extraire tout »).
     Entre DANS le dossier, sélectionne tout (Ctrl + A).
  3. Sur GitHub : « Add file » > « Upload files », puis fais glisser la
     sélection dans la page (glisser-déposer : le bouton « choose your
     files » ne prend pas les dossiers). Attends que tout soit chargé,
     puis « Commit changes ».
  4. Vérifie la page du dépôt : index.html, main.dart.js, vercel.json et
     les dossiers assets, canvaskit et icons doivent être visibles
     directement, pas rangés dans un sous-dossier.
  5. Sur vercel.com : « Add New... » > « Project » > importe ce dépôt.
     - Framework Preset : Other
     - Build Command : laisser vide (rien à construire)
     - Output Directory : laisser vide
  6. « Deploy ». Vercel donne une adresse du type
     https://mini-maisons-site.vercel.app
     Ensuite, chaque envoi de fichiers sur GitHub remet le site à jour
     tout seul.

  Si les fichiers se retrouvent dans un sous-dossier (par exemple
  « site ») : sur Vercel, Settings > Build and Deployment >
  Root Directory, mets le nom de ce sous-dossier, puis « Redeploy ».

Méthode B - avec l'outil Vercel (il faut Node.js)
  Ouvre un terminal dans le dossier vercel\site et tape :
      npx vercel --prod
  Réponds aux questions (nom du projet...). Garde les réglages proposés.


2. AUTORISER L'ADRESSE DU SITE DANS FIREBASE (à faire une fois)
--------------------------------------------------------------

Console Firebase > Authentication > Paramètres > Domaines autorisés >
« Ajouter un domaine » : colle l'adresse donnée par Vercel, sans
« https:// » (par exemple mini-maisons-site.vercel.app).

Rien d'autre à changer : les règles Firestore restent les mêmes.


3. SUR IPHONE : L'INSTALLER COMME UNE APPLI
-------------------------------------------

Ouvre l'adresse du site dans Safari, touche le bouton Partager, puis
« Sur l'écran d'accueil ». Mini Maisons s'ouvre alors en plein écran,
avec son icône, comme une vraie appli.


4. METTRE À JOUR LE SITE
------------------------

Après une modification de l'appli, relance le script
vercel\preparer_vercel.ps1 (dans le projet) : il recompile le site
(dossier vercel\site) et refait le zip. Sur GitHub, renvoie le contenu
de vercel\site de la même façon (les fichiers déjà présents sont
remplacés), ou relance « npx vercel --prod ».
