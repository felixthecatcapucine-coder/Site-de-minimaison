MINI MAISONS - LE SITE WEB (VERCEL)
===================================

Le site de Mini Maisons est déjà compilé : il n'y a rien à construire.
Il s'ouvre dans Safari sur iPhone, et sur ordinateur (Chrome, Edge,
Safari, Firefox). Les comptes, messages, maisons et points sont les mêmes
que dans l'appli Android (même base Firebase).

Dans le dossier vercel du projet :
  pour-github\   les 3 fichiers à envoyer sur GitHub (méthode A)
                 - MiniMaisons-vercel.zip : tout le site, en un seul fichier
                 - ouvrir-zip.js : Vercel s'en sert pour ouvrir le zip
                 - vercel.json : les réglages du site pour Vercel
  site\          le même site, déjà décompressé (méthode B)


1. METTRE LE SITE EN LIGNE
--------------------------

Méthode A - avec GitHub (sans rien installer)
  1. Sur github.com, crée un dépôt (par exemple « mini-maisons-site »).
  2. « Add file » > « Upload files » > « choose your files » : choisis
     les 3 fichiers du dossier pour-github, puis « Commit changes ».
     (Pas besoin de décompresser le zip : Vercel le fait tout seul.)
  3. Sur vercel.com : « Add New... » > « Project » > importe ce dépôt,
     puis « Deploy ». Les réglages sont dans vercel.json : rien à
     changer dans Vercel.
  4. Vercel donne une adresse du type
     https://mini-maisons-site.vercel.app
     Ensuite, chaque envoi sur GitHub remet le site à jour tout seul
     (en environ une minute).

Méthode B - avec l'outil Vercel (il faut Node.js)
  Ouvre un terminal dans le dossier site et tape :
      npx vercel --prod
  Réponds aux questions (nom du projet...). Garde les réglages proposés.


2. AUTORISER L'ADRESSE DU SITE DANS FIREBASE (à faire une fois)
--------------------------------------------------------------

Console Firebase > Authentication > Paramètres > Domaines autorisés >
« Ajouter un domaine » : colle l'adresse donnée par Vercel, sans
« https:// » (par exemple mini-maisons-site.vercel.app).

Rien d'autre à changer : les règles Firestore restent les mêmes.


3. SUR IPHONE : L'INSTALLER COMME UNE APPLI
-------------------------------------------

Ouvre l'adresse du site dans Safari, touche le bouton Partager, puis
« Sur l'écran d'accueil ». Mini Maisons s'ouvre alors en plein écran,
avec son icône, comme une vraie appli.


4. METTRE À JOUR LE SITE
------------------------

Après une modification de l'appli, relance le script
vercel\preparer_vercel.ps1 (Windows) ou vercel/preparer_vercel.sh (Mac),
dans le projet : il recompile le site et refait le zip. Sur GitHub, renvoie seulement le nouveau
MiniMaisons-vercel.zip (il remplace l'ancien), ou relance
« npx vercel --prod » dans le dossier site.
